Deine Meldung

Der Text und die Bilder werden öffentlich. Entferne persönliche und vertrauliche Angaben und lade nur Bilder hoch, die du veröffentlichen darfst. GitHub speichert die Meldung und ihre Anhänge. Der Meldedienst leitet die Daten an GitHub weiter und prüft sie mit Cloudflare Turnstile auf Spam.

Datenschutz und Löschung

Dieses Formular dient zur öffentlichen Bearbeitung von Fehlern und Funktionswünschen. Cloudflare prüft und vermittelt die Einsendung. Das Projekt speichert die Meldung und ihre Bilder auf GitHub. Für eine Löschanfrage wende dich an den Projektbetreiber auf GitHub und gib die Issue-Nummer an. Persönliche Angaben gehören dabei nicht in einen öffentlichen Kommentar.
